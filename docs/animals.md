# animals.md — справочник тотемных животных для VK Mini App

Документ описывает игровые профили животных для миниаппа «Тотемное животное».

Важно: это не психодиагностика и не научная классификация людей или животных. Это развлекательная модель, где животные используются как архетипы характера. Числа ниже — продуктовые веса для алгоритма подбора.

## Методологическая база

Модель использует 7 шкал:

| Шкала | Смысл |
|---|---|
| `extraversion` | социальная энергия, контактность, тяга к людям |
| `openness` | любопытство, нестандартность, тяга к новому |
| `self_control` | дисциплина, порядок, собранность |
| `agreeableness` | мягкость, эмпатия, готовность сотрудничать |
| `emotional_stability` | спокойствие, стрессоустойчивость |
| `dominance` | напор, лидерство, контроль ситуации |
| `adaptability` | гибкость, хитрость, умение выкручиваться |

Первые пять шкал связаны с логикой Big Five: экстраверсия, открытость опыту, добросовестность, доброжелательность и нейротизм / эмоциональная стабильность. `dominance` и `adaptability` добавлены как игровые продуктовые шкалы, чтобы лучше различать архетипы животных.

В исследованиях поведения животных также часто используются оси вроде смелости, агрессивности, активности, исследовательского поведения и социальности. Здесь это не переносится напрямую на реальных животных, но подтверждает сам принцип описания поведенческого профиля через измеримые шкалы.

## Диапазон значений

Все значения находятся в диапазоне `0–100`.

| Диапазон | Интерпретация |
|---|---|
| `0–30` | низкая выраженность |
| `31–69` | средняя выраженность |
| `70–100` | высокая выраженность |

## Рекомендация по алгоритму выбора

Для пользователя считается такой же вектор из 7 шкал. Затем профиль пользователя сравнивается с каждым животным по евклидову расстоянию.

```php
function findTotemAnimal(array $userTraits, array $animals): array
{
    $bestAnimal = null;
    $bestDistance = PHP_FLOAT_MAX;

    foreach ($animals as $code => $animal) {
        $distance = 0;

        foreach ($userTraits as $trait => $userValue) {
            $animalValue = $animal['traits'][$trait] ?? 50;
            $distance += ($userValue - $animalValue) ** 2;
        }

        $distance = sqrt($distance);

        if ($distance < $bestDistance) {
            $bestDistance = $distance;
            $bestAnimal = [
                'code' => $code,
                'name' => $animal['name'],
                'traits' => $animal['traits'],
                'distance' => $distance,
            ];
        }
    }

    return $bestAnimal;
}
```
